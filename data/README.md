# Data

This folder stores the raw dataset files used for training and testing our models.

## Source
**Name:** Financial Transactions Dataset: Analytics  
**Provider:** ComputingVictor  
**Link:** https://www.kaggle.com/datasets/computingvictor/transactions-fraud-datasets

## Instructions
1. Download the dataset from the link above
2. Place all files in this `data/` folder
3. Data files are not pushed to the repo since they are too large for GitHub and are sourced directly from Kaggle, so they are excluded using `.gitignore`
